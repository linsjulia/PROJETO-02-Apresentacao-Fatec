Sobre a disciplina

Técnicas de Programação ensina padrões e práticas que tornam o código mais organizado, reutilizável e fácil de manter. Estuda Design Patterns, incluindo os padrões clássicos do GoF, aplicados dentro da lógica de projeto orientado a objetos. Trabalha arquiteturas de separação de responsabilidades como MVC, MVVM e MVP, além de Desenvolvimento Dirigido a Testes.

Design Patterns Padrões de Projeto GoF Model View Controller Model-View-ViewModel Model View Presenter Desenvolvimento Dirigido a Testes Projeto Orientado a Objeto
