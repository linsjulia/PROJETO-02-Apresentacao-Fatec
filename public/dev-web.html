Sobre a disciplina

Desenvolvimento Web ensina como construir aplicações web completas, do front-end ao back-end. Estuda frameworks, arquiteturas de sistemas web e como estruturar aplicações que se comunicam com o servidor por meio de APIs. Também aborda boas práticas de controle de versionamento, essenciais para trabalhar em equipe e manter o histórico do código organizado.
